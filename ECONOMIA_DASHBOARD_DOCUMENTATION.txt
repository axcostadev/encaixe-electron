✨ FEATURES AVANÇADAS
================================================================================

1. Validação Inteligente (30%):
- Se Encaixe diferir >= 30% do Previsto, pede confirmação
- Se usuário cancelar, campo fica bloqueado por 1 segundo
- Evita edições acidentais

2. Navegação com Teclado:
- Arrow Down: próxima linha
- Arrow Up: linha anterior
- Enter: salva e foca próxima
- Tab: comportamento padrão

3. Sincronização com Arquivo:
- Busca primeiro no banco (salvamentos anteriores)
- Se não encontrar, busca no CGC.txt
- Se não encontrar, busca no OFCC.txt (fallback)

4. Modo Alto Contraste:
- Toggle no header do dashboard
- Persisted em localStorage
- Inverte cores para melhor acessibilidade

5. Charts Dinâmicos:
- Y-axis simétrico (red bars = excesso, green bars = economia)
- Labels verticais rotacionados para evitar overlap
- Suporte a visualização em R$ ou %
- Manual override para Y-axis max


📈 PERFORMANCE
================================================================================

- useMemo para filtros do banco (evita re-renders)
- requestAnimationFrame para scroll suave
- Lazy loading de gráficos (renderiza após tab ficar ativa)
- Refs para tracking síncrono (evita race conditions)
